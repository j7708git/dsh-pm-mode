## 3. 怎麼使用（給使用者）

1. 完全關閉 DSH 桌面版，重新打開。
2. 開新的空白 session，選「**DSH PM 模式**」，並把該 session 權限設為 **danger-full-access**。
3. 直接用白話說你要什麼，例如：「我想要一個可以記錄每天花費的小工具，能看一個月總共花多少。」

## 4. 怎麼帶到另一台電腦

1. 複製整個 `dsh-pm-mode` 資料夾（含 `.git` 更好），放哪裡都行。
2. 用 DSH 在該資料夾開 session，說：「請讀 README 並幫我安裝 dsh-pm-mode」。
3. agent 依 `AGENTS.md`／README 的 runbook 自動判斷平台、安裝、驗證，並請你重啟 DSH。
4. 安裝後資料夾可移動或刪除；要更新版本就覆蓋後再跑一次安裝。

## 5. 已知限制

- session 權限需為 `danger-full-access`（本機 `workspace-write` 沙箱無法執行 shell／git）。
- 模式只在**新 session** 生效；既有對話不會改變。
- 沒有 `dsh` 指令或 `node` 時，驗證會降級（跳過 dump 差異／YAML 解析）並以警告呈現，其餘檢查照做。
- 不安裝任何額外插件也能運作；`plugin_manager` 只是讓 PM 能在你同意後安裝研究到的工具。
- v1.1 尚未在 macOS / Linux **真機**上跑過（bash 版僅在 Windows Git Bash 與假 DSH home 上實測）。
- v1 不含 Agent Teams（列為 v2 選項）。

## 6. 回滾

`.\scripts\uninstall.ps1`（或 `bash scripts/uninstall.sh`）→ 重啟；
或直接用 `<DSH_HOME>/profiles/<profile>/cordis.patch.yml.bak-pm-<時間>` 還原。
